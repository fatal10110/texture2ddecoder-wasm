unity-asset-reader - CDN example

Pick a Unity AssetBundle: its objects are listed, and a Texture2D is drawn to the canvas. No bundler and no install: the packages come from jsDelivr, and the reader runs in a Worker, so the page stays responsive while a big bundle loads. No special headers (COOP/COEP) are needed; serve this folder over HTTP (not file://).
?local loads this repo's builds instead, from node examples/serve.mjs (see examples/README.md).

Pick a file.
# Class Name Path ID Bytes

How this works (the Worker, cdn-worker.js): 
const CDN = "https://cdn.jsdelivr.net/npm";
const { load, ClassID } = await import(`${CDN}/unity-asset-reader@1.0.0/+esm`);
const { initTexture, decodeTexture2D } =
  await import(`${CDN}/unity-asset-reader-texture@1.0.0/+esm`);
// In a Worker this needs texture2ddecoder-wasm 1.2.3 or later (#149).
await initTexture({ wasmPath: `${CDN}/texture2ddecoder-wasm@1/wasm` });

const env = load([{ name: file.name, data: new Uint8Array(await file.arrayBuffer()) }]);
for (const obj of env.objects) {
  if (obj.type === ClassID.Texture2D) {
    const { data, width, height } = await decodeTexture2D(obj.read()); // RGBA, top row first
    // postMessage it to the page, which draws it:
    // new ImageData(new Uint8ClampedArray(data.buffer), width, height)
  }
}
Import maps do not apply inside a Worker, so the Worker imports jsDelivr's /+esm builds, which point the packages' own imports at the CDN too.
